# Добро пожаловать на стажировку .NET (Fintech Edition)

## Вводная по проекту: «CoreLedger» (Процессинговый центр)

Мы строим ядро финтех-системы для учета электронных кошельков и проведения транзакций между счетами. В финтехе главная боль — потеря или дублирование денег при параллельных запросах. Поэтому наш фокус будет на идемпотентности, блокировках и надежности.

## Стек проекта

- .NET 8 / 9 (ASP.NET Core Web API)
- PostgreSQL (основная БД)
- EF Core (с акцентом на транзакции и оптимистичные/пессимистичные блокировки)
- Redis (кэширование и распределенные блокировки / идемпотентность)
- RabbitMQ + MassTransit (асинхронные уведомления и события)
- xUnit + Testcontainers (интеграционные тесты на реальной БД)
